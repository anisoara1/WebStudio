
# 🌐 WebStudio — Modern Business Landing Page

Un website de prezentare modern, responsiv și optimizat pentru companii și servicii digitale. Proiectul pune accent pe design curat, structură clară și o experiență vizuală profesionistă, potrivită pentru portofoliu și demonstrarea abilităților front‑end.

---

## ✨ Funcționalități principale

- **Design modern și profesionist**, potrivit pentru agenții, freelanceri sau companii tech.  
- **Structură clară**: secțiuni pentru servicii, portofoliu, echipă și contact.  
- **Navigație intuitivă** cu meniu fix și ancore către secțiuni.  
- **Responsive design** pentru desktop, tabletă și mobil.  
- **Galerie de proiecte** cu hover effects elegante.  
- **Formular de contact** stilizat (fără backend).  
- **Tipografie și culori moderne**, inspirate din design corporate.

---
